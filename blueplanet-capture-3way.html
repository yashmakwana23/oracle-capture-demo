What the 3 sources show

Here the two prod runs mostly AGREE on timing — unlike the Stage 187 video, where the arm_b MD drifted onto the wrong stage/level. Both anchor the same beats at nearly the same seconds: victory at 6:09, tutorial hand at 6:14, the HK$8 weapon-morph at 6:57, and the two mid-combat buff picks at 0:32 / 2:21.

Where they differ is granularity — and, notably, the API is the more detailed prod run here (the opposite of the usual arm_b-richer pattern):
- API logs the gear/purchase flow as separate steps — necklace replace (6:21), Iron Armor enhance (6:24), Iron Ring review/replace (6:32), dismantle-Congrats claim (6:38), Weapon Morph browse (6:44), HK$8 attempt (6:57). The arm_b MD compresses these: one king_feature_equipment_review for the necklace, one for the ring, one reward_claiming for the dismantle, one king_feature_equipment_review for the skins.
- Conversely, arm_b logs purchase_failure at 7:06 (the cancellation) which the API omits entirely — the API event list stops at the 6:57 payment attempt, so it never records that the transaction was cancelled.
- Both prod summaries omit the exact numbers and denials the transcript carries: 49% HP at clear, the 36 gold / 8 gems dismantle yield, the "Insufficient gear blueprints" denial, and the fact that the HK$8 purchase (Google Play "Gift Pack 3") was ultimately cancelled (the API summary even implies the microtransaction succeeded — "concludes with a microtransaction purchase").

Three notable cross-source differences

  1. Purchase outcome: transcript + arm_b MD both record the HK$8 attempt was cancelled ("Transaction cancelled" / purchase_failure); the API drops the cancellation and its Video_Summary reads as if the purchase completed.
  2. Gear-flow granularity: API splits the equipment/dismantle sequence into 7 discrete events (necklace, armor enhance, ring, dismantle-claim, weapon-morph browse, payment); arm_b MD folds the same window into ~5 compressed events.
  3. Numbers only the transcript has: 49% remaining HP, per-unit victory damage (111K/92.7K/39.5K/3K), Idle Efficiency 142.98/h, dismantle yield 36 gold + 8 gems, ATK deltas (+10→+27, armor 0→6), the "Insufficient blueprints" denial, and three stage/guild lock messages — none of which appear in either prod output.
